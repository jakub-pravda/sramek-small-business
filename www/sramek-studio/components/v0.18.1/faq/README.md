# FAQ akordeon

Přenositelný nativní akordeon bez frameworku. HTML `<details>/<summary>` zůstává funkční i bez JavaScriptu; malý skript pouze zajišťuje, že je otevřená nejvýše jedna odpověď i v prohlížečích bez podpory atributu `name`. Šipka se při otevření otočí o 180° a animace respektuje `prefers-reduced-motion`.
